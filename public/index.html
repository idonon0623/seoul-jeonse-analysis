04 / API COMPARISON

API 전체 페이지 조회 및 전세 필터 적용 결과
접수·계약연도조회 전월세 행 수분석 전세 건수㎡당 중앙값 (만원/㎡)

각 접수연도의 자료 중 계약연도도 같은 전세만 포함합니다. 월세 0, 양수 보증금·면적, 유효한 날짜·대상 주택유형을 확인합니다. API에는 고유 거래 ID가 없어 동일한 값을 가진 행도 임의로 제거하지 않습니다. 월 3건 미만은 그래프에서 제외합니다. 접수·계약연도가 다른 신고와 2026년 접수분은 포함하지 않으므로, 계약연도로 재분류한 위 파일 기반 집계와 직접 일치하지 않습니다. 정정·갱신 시점도 다를 수 있습니다. 진행 중이거나 실패한 조회를 완전한 집계로 표시하지 않습니다.

METHOD & SOURCES

어떤 데이터로, 어떻게 분석했나요?

A

기간과 대상

2021년 1월 1일–2025년 12월 31일 계약을 대상으로 합니다. 2026년은 진행 중이므로 완결된 최근 5개 연도를 선택했습니다. 전세로 표시되고 월세가 0인 아파트·연립다세대·단독다가구·오피스텔을 포함합니다.

B

가격 지표

주 지표는 계약별 보증금(만원)을 임대면적(㎡)으로 나눈 값의 중앙값입니다. 평균과 보증금 중앙값을 보조 지표로 제공합니다. 지역별 중앙값을 다시 평균하지 않고 해당 계약 전체에서 직접 계산합니다.

C

전처리와 검증

계약일을 기준으로 연도·월을 구분합니다. 서로 다른 원본 파일에 중복 수록된 동일 기록은 숫자·공백을 정규화해 한 번만 반영합니다. 같은 파일 안의 동일 기록은 별개 계약일 수 있어 유지합니다. 양수 보증금·면적, 서울 25개 구, 대상 유형을 확인합니다.

D

해석의 범위

신고 자료의 구성 변화, 신규·갱신 계약 혼합, 신고 지연과 정정에 영향을 받습니다. 원본은 접수연도별 공개 파일이므로 2026년에 접수된 2025년 계약은 포함되지 않습니다. 물가를 조정하지 않은 명목가격이며 동일 주택의 반복 거래 가격지수가 아닙니다.

특히 공개 파일의 전체 전월세 행 수는 2024년 522,001행, 2025년 1,084,942행으로 크게 다릅니다. 파일 수록 범위·정정 시점의 차이를 배제할 수 없으므로 행 수 증가를 시장 전체 거래량 증가로 해석하지 않습니다. 월별 그래프는 3건 이상, 연간 변화율·유형 비교는 연도별 30건 이상일 때 표시합니다. 집계표와 CSV에는 소표본도 건수와 함께 남깁니다.

원본 파일별 포함·제외 건수 확인

순차적으로 제외하므로 각 행의 ‘포함 + 제외’는 원본 행 수와 일치합니다. 가격·면적 항목에는 월세가 0이 아닌 전세 표시 기록도 포함됩니다.
