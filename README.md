# 서울의 전세, 5년의 기록

과제 2: **지난 5년간 서울시 전세가격 변화 분석**.

- 분석 기간: 2021-01-01–2025-12-31 (계약일 기준, 최근 5개 완결연도)
- 주 지표: 계약별 전세보증금 ÷ 임대면적의 중앙값 (만원/㎡)
- 보조 지표: ㎡당 평균, 보증금 중앙값, 계약 건수
- 시각화: **Plotly 그래프 3개** — 월별 추세, 25개 자치구 변화율, 주택유형별 연간 추세
- 분석 결과: [ANALYSIS.md](ANALYSIS.md), 웹앱의 ‘데이터에서 읽은 네 가지’
- Python 소스: [scripts/analyze.py](scripts/analyze.py), [analysis.ipynb](analysis.ipynb)
- 공개 사이트: https://seoul-jeonse-analysis.pages.dev
- GitHub: https://github.com/idonon0623/seoul-jeonse-analysis

## 핵심 결과

공식 공개 파일에서 전처리를 통과한 **1,455,298건**을 분석했습니다.
서울 전체 ㎡당 보증금 중앙값은 2021년 590.0만원 → 2025년 669.3만원으로 **13.4%** 높아졌습니다.
전년 대비 변화는 2022년 +4.5%, 2023년 −2.3%, 2024년 +6.8%, 2025년 +4.0%입니다.

아파트의 ㎡당 중앙값은 10.4%, 오피스텔은 7.1% 높아졌고, 연립다세대는 2.6%, 단독다가구는 0.2% 낮아졌습니다.
분석 자료에서 아파트 계약 비중은 42.2% → 58.9%로 달라졌습니다. 전체 지표에는 거래 구성 변화도 반영되므로 동일 주택의 가격 상승률로 해석할 수 없습니다.

## 실행

5년 기본 분석은 미리 생성한 집계 데이터를 사용합니다. 추가된 **서울시 API 재조회**는 Cloudflare Pages Functions가 `SEOUL_API_KEY`를 사용하여 실제 서울시 API를 호출합니다.
로컬 API 개발은 프로젝트 루트의 Git 제외 파일 `.dev.vars`에 `SEOUL_API_KEY`를 설정한 뒤 `npm run dev`로 실행합니다. 키를 공개 코드나 채팅에 붙여넣지 마세요.

```sh
npm start
# http://127.0.0.1:4173 — 파일 기반 분석만 미리보기
npm run dev
# http://localhost:4174 — API와 정적 파일 함께 실행 (.dev.vars 필요)
npm test
# 실제 인증키 없이 서버 필터·페이지네이션·비밀정보 비노출 단위 테스트
```

GitHub/Cloudflare 빌드에서는 원본을 다시 다운로드하지 않습니다. `public/`에 검증된 집계와 Plotly 라이브러리를 포함했습니다.

## 분석 재현

Python 3.11 이상을 권장합니다. 전체 원본 약 74MB 압축 파일을 읽으며, 전처리에는 수 GB의 메모리가 필요할 수 있습니다.

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python scripts/download_data.py
python scripts/analyze.py
npm run build
```

원본 파일은 `data/raw/`에 저장하며 Git에서 제외합니다. `data/sources.json`에 다운로드 파일의 SHA-256을 기록합니다.
분석 스크립트는 체크섬, 5개 연도·60개 월·25개 구, 원본 포함/제외 건수 합계, 지역 합계와 서울 전체 합계, 원자료 중앙값과 집계값 일치를 검증합니다.

`analysis.ipynb`에서는 집계 CSV를 DataFrame으로 읽고 `px.line`, `px.bar`로 같은 세 그래프를 직접 생성할 수 있습니다.
`scripts/analyze.py`도 Plotly Express로 세 Figure를 생성하고 `fig.write_html()`로 저장합니다.

## 데이터와 방법

출처: [서울 열린데이터광장 — 서울시 부동산 전월세가 정보 OA-21276](https://data.seoul.go.kr/dataList/OA-21276/S/1/datasetView.do).
서울특별시 제공, 국토교통부 실거래가 공개시스템 연계. 공공누리 제1유형(출처표시).
2021–2025년 연도별 공개 ZIP을 **2026-09-28**에 내려받은 스냅샷을 사용했습니다.

1. 접수연도로 나뉜 5개 파일을 읽고 문자열 공백과 숫자 표기를 정규화합니다.
2. 이전 파일에 이미 수록된 동일한 정규화 기록은 이후 파일에서 제외합니다. 파일 간 중복 총 6,213행입니다. 고유 거래 ID가 없어 완전한 거래 식별은 불가능하며, 같은 파일 안의 동일 행은 별개 계약일 수 있으므로 유지합니다.
3. 전세 표시, 월 임대료 0, 양수 보증금·임대면적을 요구합니다. 임의 상·하위 분위수 절삭은 하지 않습니다.
4. 계약일이 2021–2025년에 속하며 서울 25개 구·4개 주택유형에 속하는 기록만 포함합니다.
5. 모든 중앙값은 해당 그룹의 **개별 계약**에서 직접 계산합니다. 하위 그룹의 중앙값을 평균하지 않습니다.
6. 변화율은 `(2025년 대표값 / 2021년 대표값 - 1) × 100`입니다. 5개 연도를 포함하지만 양 끝의 경과기간은 4년입니다. 전년 대비는 직전 연도 대표값과 비교합니다.
7. 사이트의 월별 그래프는 3건 이상, 연간 변화율·유형 비교는 30건 이상을 표시합니다. CSV·집계표는 모든 비어 있지 않은 그룹을 제공합니다.

지역 필터는 월별 그래프·핵심 지표·집계표·주택유형 그래프에 적용됩니다. 자치구 그래프는 항상 25개 구를 비교하고 선택 구를 강조합니다.
주택유형 필터는 핵심 지표·월별 그래프·자치구 그래프·집계표에 적용됩니다. 유형 그래프는 비교를 위해 항상 네 유형을 표시합니다.
독립 HTML 파일과 결과 해석 네 문단은 기본 조건(서울 전체·전체 유형·㎡당 중앙값)입니다.

## 한계

- 2026년은 진행 중이므로 연간 비교에서 제외했습니다. ‘최근 5년’을 2022–2026년으로 정의하는 접근과는 구분됩니다.
- 2026년에 접수된 2025년 계약은 이 스냅샷에 없습니다. 신고 지연·정정 및 원본 파일의 갱신 시점에 따라 결과가 달라집니다.
- 공개 전월세 파일 행 수는 2024년 522,001행, 2025년 1,084,942행입니다. 수록 범위 차이를 배제할 수 없어 건수 증가를 전체 시장 거래량 증가로 단정하지 않습니다.
- 주택유형, 면적, 건축연도, 신규·갱신 계약 구성 변화의 영향을 받습니다. ㎡당 지표도 품질 차이를 완전히 통제하지 못합니다.
- 명목가격이며 물가 조정, 반복매매/반복임대 지수, 인과추론을 수행하지 않았습니다. 금리·정책 영향은 본 자료만으로 주장하지 않습니다.

## Cloudflare 배포

정적 파일과 `functions/api/rent.js`를 Cloudflare Pages에 함께 배포합니다. API 재조회에는 **SEOUL_API_KEY Secret이 필요합니다**.
`.env`, `.dev.vars`, 원본 거래 파일과 로컬 캐시는 Git 및 배포 대상에서 제외합니다.
브라우저는 같은 사이트의 `/api/rent`를 호출합니다. 서버만 Secret을 읽어 `tbLnOpendataRentV`에 요청합니다.
키를 포함한 원본 API URL, 원본 오류 메시지, 주소·건물명은 브라우저 응답에 포함하지 않습니다. 서버 오류에도 키나 원본 URL을 출력하지 않습니다.

Cloudflare 대시보드 → Workers & Pages → `seoul-jeonse-analysis` → 설정 → 변수 및 비밀에서
프로덕션 환경에 이름 `SEOUL_API_KEY`, 유형 **Secret**으로 서울 열린데이터광장 인증키를 등록하세요. 등록 후 재배포가 필요합니다.
CLI를 사용할 경우 아래 명령의 비공개 입력 프롬프트에 키를 입력합니다. 키 값을 명령행 인수로 쓰지 마세요.

```sh
npx wrangler pages secret put SEOUL_API_KEY --project-name seoul-jeonse-analysis
```

```sh
npm ci
npx wrangler login
npm run deploy
```

이 프로젝트는 **직접 업로드(Direct Upload)** 방식입니다. GitHub의 `main` 브랜치와 동일한 `public/` 파일 및 Pages Functions를 Wrangler로 발행합니다.
**GitHub 푸시만으로 자동 배포되지는 않습니다.** 수정 후 `git push`와 `npm run deploy`를 각각 실행하세요.
GitHub 자동 연동 API가 오류를 반환해 직접 업로드 방식을 사용했습니다.
새 프로젝트 생성 시 Wrangler 4.151의 Workers 전환을 피하려고 `wrangler pages project create seoul-jeonse-analysis --production-branch main --force`를 사용했으며, 이후 기존 프로젝트에 배포할 때는 `--force`가 필요 없습니다.

Plotly.js는 MIT 라이선스이며 배포 파일의 원래 라이선스 주석을 유지합니다. Noto Sans KR은 Google Fonts에서 제공되며, 폰트 연결이 없어도 시스템 한글 폰트로 표시됩니다.

## API 조회 범위와 해석

- 서울시 공식 안내에서 OpenAPI는 최근 3개 접수연도만 제공합니다. 따라서 **2021–2025년 전체를 현재 API만으로 복원할 수 없습니다**. 5년 전체 분석·기존 해석은 공식 파일 기반으로 유지합니다.
- 추가 API 패널은 완결연도인 2024·2025년, 선택한 자치구의 모든 페이지를 조회합니다. 2026년 진행 중 자료는 연간 비교에서 제외합니다. 제공 범위가 이동하면 지원 연도를 다시 검토해야 합니다.
- 서버는 요청당 최대 1,000행을 받아 분석 필드만 반환합니다. 브라우저는 두 연도의 다음 페이지를 순서대로 이어받고, **전체 건수와 수집 건수 일치 시에만** 가격을 계산합니다. 첫 1,000행을 전체로 간주하지 않습니다. 자치구·연도당 20만 행을 초과하면 잘린 통계 대신 오류를 표시합니다.
- 전세, 월세 0, 양수 보증금·면적, 대상 유형·지역, 유효한 계약일을 확인합니다. 각 접수연도 안에서 계약연도도 동일한 기록만 비교하므로, 기본 5년 집계(파일들을 합친 후 계약연도로 분류)와 모집단이 다릅니다. API 정정·갱신 시점과 2026년 접수분 누락도 차이를 만듭니다.
- 고유 거래 ID가 없으므로 API의 동일값 행은 임의 중복 제거하지 않습니다. 월 3건 미만은 그래프에서, 연 30건 미만은 연간 변화율에서 제외합니다. 중앙값은 개별 계약의 보증금/면적에서 계산합니다.
- 같은 조건의 응답은 최대 15분 캐시합니다. 실제 API 응답 수집 시각을 표시하며 캐시 조회 시각을 새 수집 시각으로 위장하지 않습니다. 페이지별 수집 시점이 달라질 수 있고 원본 API가 고정 스냅샷을 제공하지 않아 수정 중인 데이터의 완벽한 일관성은 보장할 수 없습니다. 조회 중 전체 건수가 바뀌면 결과 표시를 중단합니다.
- 키 미등록·인증 실패·통신 실패는 명시적으로 표시하고, 파일 데이터를 API 응답처럼 대체하지 않습니다.
